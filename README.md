# 3d-Tetris

## Overview
This project is a modern take on the classic Tetris game, implemented with 3D graphics for an enhanced visual experience. It utilizes HTML, CSS, and JavaScript, providing a smooth and interactive gameplay experience. Players can rotate and move blocks using keyboard controls, and the objective remains the same: complete horizontal lines to earn points and prevent the blocks from stacking to the top of the screen(There are some bugs needs to be improved).

---

## Features
- **3D Visuals**: Dynamic and visually engaging 3D blocks.
- **Interactive Gameplay**: Keyboard controls for moving and rotating blocks.
- **Real-Time Scoring**: Updates points in real time based on completed rows.
- **Responsive Design**: Optimized for various screen sizes.

---

## Technologies Used
- **HTML**: For structuring the game interface.
- **CSS**: For styling and 3D transformations.
- **JavaScript & jQuery**: For game logic and interactivity.
